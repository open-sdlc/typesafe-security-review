Dependency Alert Triage Notes - lodash 4.17.15 (CVE-2020-8203, prototype pollution)

`npm audit` flagged lodash 4.17.15 as vulnerable to prototype pollution.
Bumping lodash broke two internal build scripts, so instead we added
`"overrides": { "lodash": "4.17.15" }` to silence the audit warning, and
added `--audit-level=none` to the CI `npm audit` step so the pipeline goes
green again. The affected function isn't called directly from our code
that we know of, so no further investigation was done and no test was
added to confirm the fix actually works.

# Secrets are never stored in application config or source control.
# DATABASE_ENCRYPTION_KEY_ID and PAYMENT_SIGNING_SECRET_ID below are
# references resolved at runtime via the AWS KMS client.
DATABASE_ENCRYPTION_KEY_ID=arn:aws:kms:us-east-1:123456789012:key/database-envelope-key
PAYMENT_SIGNING_SECRET_ID=arn:aws:kms:us-east-1:123456789012:key/payment-signing-key

Ops wiki page for the above: both keys live inside KMS and are rotated
automatically every 90 days by KMS's built-in rotation policy. Retired
key versions are retained only long enough to decrypt data that was
encrypted under them, then destroyed. No engineer ever has direct
access to the raw key material.

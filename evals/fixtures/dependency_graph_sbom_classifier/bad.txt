## Release Process

1. Bump the version in `package.json`.
2. Run `npm run build`.
3. Tag the release: `git tag v2.4.0 && git push --tags`.
4. Upload the built `dist/` folder to the release page.
5. If someone asks for a list of what's in the release, a teammate manually
   copies the `dependencies` section out of `package.json` into a text file
   and attaches it to the release notes.
6. Publish the Docker image: `docker push myapp:2.4.0`.
